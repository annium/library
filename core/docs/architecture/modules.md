# Modules

Every directory under `base/<Group>/src/` is an independently-packaged module. Group directories exist to visually cluster related modules in the solution — they are not shipped.

## Annium (root)

Folder: `base/Annium/src/`

| Package | Responsibility |
|---------|----------------|
| `Annium` | Zero-dependency primitives used everywhere: extensions (`ArrayExtensions`, `ByteExtensions`, `DateTimeExtensions`, etc.), `Disposable`/`DisposableBox`, `AsyncLazy`, `IActionScheduler`, `ITimeProvider`, `ITrackingWeakReference`, `HashCodeSeq`, plus `Collections/`, `IO/`, `Net/`, `Linq/`, `Logging/` helpers. |
| `Annium.Analyzers` | Roslyn analyzers shipped alongside `Annium` (exception-naming rules, visibility checks). Loaded automatically by consumers. |
| `Annium.Testing` | `TestBase`, fluent assertions, `Wrap.It(...)`, `Expect`, `TestLog`. See [Testing](../guides/testing.md). |

## Architecture

## Identity

Folder: `base/Identity/src/`

| Package | Responsibility |
|---------|----------------|
| `Annium.Identity.Tokens` | Token abstractions + RSA/EC signing primitives. |
| `Annium.Identity.Tokens.Jwt` | JWT issuance and validation on top of `System.IdentityModel.Tokens.Jwt`. |
